# Cobble & Candle documentation

Setup guides, how-tos and support for the **Cobble & Candle** WordPress theme and its **Cobble & Candle Core** plugin. The theme is sold at [matthummel.com](https://matthummel.com/); the source repository is private. These docs are public so anyone can see how the theme works before buying.

## Owner guide

## About this repository

Documentation only, no theme code. To fix a typo or an out-of-date step, open a pull request. For help with your own site, use [Support](support.md); please do not post site details or guest data in a public issue.
